# 嘴替 · 招式体系设计方案（v2）

> 目标：把系统从「答案库驱动」改成「招式库驱动 + 自我学习驱动」。
> 让 AI 学会「怎么回」，而不是只记住「这句应该怎么回」。
> 本文是**设计方案**，不是代码改动。所有结论基于对现有 39 个案例 + 8 个 strategy 的逐条反向拆解。
> 标记说明：`语料支撑强`=39 案例中多次独立出现、可交叉验证；`语料支撑中`=有样本但较少，属"结构上必须存在、可由其本性迁移"；`不足以判断`=现有语料无法独立验证，需要设计定义或后续补样本。

---

## 一、现有 39 案例分析结果

### 1.1 语料画像（先看清"我们手里有什么"）
- **39 个案例高度偏向"回应式回怼"**：绝大多数是"对方先攻击/阴阳/贴标签 → 我反击"。这是单一博主的作品集，不是全场景嘴替语料。
- **少数非回怼类**（撩/安抚/哄）约 10 个，集中在 crush/恋爱场景：`haolei`、`hong`、`chicu`、`caicai`、`renji`、`yidubuhui`、`zhaohua`、`huachi`、`juejiao`、`daifan`、`fenshou` 中的一部分。
- **立边界类**（拒绝被使唤/拒绝越界）只有 `tuodi` 一个案例，样本极少。

### 1.2 核心发现
**发现 A：真正可复用的是"动作"，不是"句子"。**
39 个案例表面五花八门，但底层动作高度收敛。例：
- `我还能靠关系让你出去`（guanxi）与 `你领导是谁`（guanxi）与 `那你让他们都走呗`（xianzou）与 `明天该你了`（ke）——用的是**同一个动作：把攻击/问题反抛给对方，逼对方去处理**。
- `不敏感还不知道你这么坏`（taimingan）与 `你的恶意太明显`（taimingan）与 `这么在意我的情绪`（nijile）——用的是**同一个动作：把对方安给你的帽子原样扣回 / 点破对方动机**。

**发现 B：`trigger（场景）`不等于`招式（动作）`。**
同一个场景（职场/被质疑能力）下会用到不同招式；同一个招式能跨完全不同的场景（见压力测试）。所以**分类必须按动作，不能按场景**。

**发现 C：现有 8 个 strategy 是"动作 + 语气"混在一起的，且多数缺定义。**
`high-cold（高冷）`、`阴阳`本质是**语气/风格**，不是动作；`安抚`本质是**目标模式**，不是冲突招式；`转移`是`反问/装傻/荒诞`的子集，不是独立招式。且 8 个文件里多数 `how_to_use / avoid_when` 是空的——抽象没有完成。

**发现 D：回应里混着 3 种"力气来源"，必须分清。**
- ① 招式（做了什么动作）→ 决定"为什么有效"
- ② 语气（怎么说的）→ 决定"给人什么感觉"
- ③ 强度（多狠）→ 决定"杀伤力多大"
现在的 strategy 把三者揉成一团，导致既不能精确匹配、也不能跨场景复用。

## 二、最终招式体系

三层正交结构：

```
冲突回应（9 个真·招式）               目标模式（2 个）              语气（正交维度）
┌────────────────────────────┐   ┌──────────────────────┐   ┌──────────────────────┐
│ 守势·破前提                  │   │ G1 关心·接住情绪        │   │ 冷淡 / 阴阳(讽刺)       │
│  M1 不接（总纲）             │   │ G2 撩·暧昧推拉          │   │ 犀利(直接) / 幽默       │
│  M6 装傻·留白              │   └──────────────────────┘   │ 温和 / 强硬            │
│  M7 冷处理                 │                              │ 高冷(霸总) / 无辜装傻    │
│ 攻势·回敬                  │                              │ 调侃(玩笑) / 无厘头     │
│  M2 反问施压               │                              │                       │
│  M3 扣回·诛心              │  攻击强度 1-5                 │                       │
│  M4 捧杀                   │                              │                       │
│  M5 荒诞化                 │                              │                       │
│ 守边界·自保                │                              │                       │
│  M8 立边界                 │                              │                       │
│  M9 自嘲接梗               │                              │                       │
└────────────────────────────┘                              └──────────────────────┘
```

一句话：**招式回答"做什么"，语气回答"怎么说"，强度回答"多狠"，目标模式回答"这一场要达成什么"。** 场景是无限输入，招式是有限方法。

## 三、每个招式详细定义

> 强度分 5 档：1=几乎无害（纯化解/卖萌）2=轻刺（带一点不舒服）3=中等（明显反击）4=强（当面打脸）5=极强（诛心/不留余地）。
> 所有"核心结构"都是**给 LLM 执行的动作指令**，不是具体句子。

---

### M1 · 不接（拒绝进入解释模式）——守势总纲

1. **核心逻辑**：对方给你贴标签或设陷阱式前提（"你是不是靠关系""你太敏感了"），一旦你解释，你就默认了对方的定义。不接 = 不解释、不辩解，直接不承认对方设定的话头成立。
2. **解决什么问题**：被质疑能力/身份/人品/动机时，避免"越解释越像心虚"。
3. **适用场景**：对方挑衅式提问、贴标签、阴阳；任何想"跳出对方设定"的关系（平级/陌生/被纠缠）。
4. **不适用场景**：对方是真心关心的长辈/恋人，需要真诚回应时；对方手里有实锤事实（你真做错了）时，硬不接显得狡辩。
5. **核心结构**：识别对方前提 → 明确"我拒绝承认这个前提" → 不进入解释 → 把话头甩回对方（转给 M2/M3）或直接中断（转 M6/M7）。
6. **生成步骤**：①标注对方的"前提/标签"；②决定不解释；③选择落地动作：反问施压 / 扣回 / 装傻 / 冷处理。
7. **语气**：犀利 / 冷淡 / 无辜装傻 / 高冷，均可用。
8. **强度**：2–5。
9. **典型案例**：`你是不是关系户？`→ 不解释"我不是"，而是 `你不是吗，那你完了`（转扣回）。
10. **跨场景迁移**：
    - 职场：`你怎么还没做完？`→`你是在查岗还是想接手？`（不接"我慢"的前提）
    - 恋爱：`你根本不重视我`→`那你觉得我该重视你哪一点？`（不接"不重视"的前提）
    - 陌生人：`你是不是没素质？`→`你认识我？`（不接前提，反问）
    - 家庭：`你怎么还不结婚？`→`你比我爸妈还操心`（不接"该结"的前提）

---

### M2 · 反问施压（逼对方自证 / 下不来台）

1. **核心逻辑**：不回击内容，而是用一个"让对方必须自证/作答"的反问，把举证责任推回对方。
2. **解决什么问题**：对方随口贬低/越界时，让"该解释的人"从你变成他。
3. **适用场景**：被质疑能力/身份、被越界打听、被阴阳；希望一句话让对方闭嘴时。
4. **不适用场景**：对方是上位者且你在意关系（反问易被当顶撞）；场合极严肃（汇报/面试）。
5. **核心结构**：抓对方话里的一个"经不起反问的点" → 抛出一个对方答不上/答了就露怯的问题 → 停止，等对方接。
6. **生成步骤**：①找出对方话里最站不住的地方；②构造一个封闭性反问（答案会反噬对方）；③不问多余的字。
7. **语气**：犀利 / 冷淡 / 阴阳。
8. **强度**：3–5。
9. **典型案例**：`你领导是谁`（guanxi）、`你说哪里`（taimingan）、`那你一定没急吧`（nijile）。
10. **跨场景迁移**：
    - 职场：`你穿得真土`→`土不土，你说了算还是我说了算？`
    - 恋爱：`你好像不爱我了`→`那我该怎么做你才觉得我爱？`
    - 朋友：`你这次考得真差`→`那你考个好的我看看？`
    - 网络：`就这水平还发帖`→`那你倒是发个不水的？`

---

### M3 · 扣回 / 诛心（反扣帽子 / 点破动机）

1. **核心逻辑**：把对方安给你的负面标签**原样扣回对方**，或直接点破对方说这话的真实动机，让对方失去攻击合理性。
2. **解决什么问题**：对方靠"贴标签/站在道德高地"攻击你；戳破后他站不住脚。
3. **适用场景**：被贴标签（敏感/急了/爱表现/不合群）、被道德绑架、被阴阳。
4. **不适用场景**：对方是家人/恋人且是真关心（扣回会伤感情）；公开场合扣太狠会显得你攻击性强。
5. **核心结构**：接收对方标签 → 找到对方的同款行为/动机 → 把同一个标签还给对方，或点破"你这么说是因为 X"。
6. **生成步骤**：①不接对方标签；②找对方自身的同类破绽或说这话的动机；③用"其实是你的问题"收口。
7. **语气**：阴阳 / 犀利 / 冷淡。
8. **强度**：3–5。
9. **典型案例**：`你太敏感了`→`是你的恶意太明显`；`你急了`→`这么在意我的情绪`；`你是不是爱表现`→`原来你是来混日子的啊`。
10. **跨场景迁移**：
    - 职场：`你怎么这么爱抢功`→`那你功劳是被谁抢走的？`
    - 恋爱：`你太黏人了`→`你不黏我，是忙着黏别人吗？`
    - 家庭：`你脾气真差`→`是，不然镇不住你这张嘴。`
    - 陌生：`你挤什么挤`→`你不挤，是路太宽还是你太闲？`

---

### M4 · 捧杀（顺着对方的框架说反话 · 表面客气实则带刺）

1. **核心逻辑**：不硬碰，而是**顺着对方的话，用礼貌/夸奖的外壳说出攻击性内核**，让对方挑不出毛病又难受。
2. **解决什么问题**：不想撕破脸、人多场合、对方身份让你不宜直接怼时，仍能反击且保住体面。
3. **适用场景**：阴阳、攀比、当众贬低、需要"表面和气"的场合（职场/饭局/亲戚）。
4. **不适用场景**：对方真心帮你/夸你时（会变成阴阳好人）；关系亲密且你不想伤对方。
5. **核心结构**：先认同对方框架（"你说得对/是啊/谢谢"）→ 在认同里塞进反讽 → 保持礼貌语气。
6. **生成步骤**：①接住对方的话头（不反驳）；②在"夸"或"顺"的外壳里植入一句反刺；③语气保持淡定/礼貌。
7. **语气**：阴阳（核心是捧杀，不是直白攻击）。
8. **强度**：2–4（表面无攻击，内里带刺）。
9. **典型案例**：`太好了，还以为你对我没感觉`（buxihuanni）、`你太破费了，为了让我丢人`（qing）、`你带着，我以为很便宜呢`（bingui）、`主要是你也没拿过奖金，我怕你回请不起`（jiangjin）。
10. **跨场景迁移**：
    - 职场：`你这方案真不咋样`→`是啊，下次让您来教我们什么叫好。`
    - 恋爱：`你厨艺真差`→`是，所以只配喂你这种挑剔的。`
    - 朋友：`你这照片拍得真一般`→`谢谢，摄影这块还得向您这"专业"的请教。`
    - 亲戚：`你今年又没涨工资啊`→`是啊，比不了您这天天盯着我钱包的。`

---

### M5 · 荒诞化（夸张到荒谬 · 架空攻击）

1. **核心逻辑**：不正面回应，把对方的攻击**升级到一个荒谬的虚构场景**，让攻击本身失效，并显得对方可笑。
2. **解决什么问题**：被开恶劣玩笑/被贬低/被围攻时，用"离谱到没法接"化解，比硬怼更显松弛。
3. **适用场景**：无厘头互怼、当众被开涮、想轻松收场、对方攻击不伤大雅时。
4. **不适用场景**：对方是严肃长辈/领导（荒诞易被视为不尊重）；对方认真求助/示弱时。
5. **核心结构**：取对方话里一个元素 → 把它推进一个明显荒诞/夸张/反常规的场景 → 用一本正经的口吻说出来。
6. **生成步骤**：①抓对方话的"梗点"；②把它放到极端/反逻辑情境；③用淡定口吻讲。
7. **语气**：无厘头 / 幽默 / 冷淡。
8. **强度**：1–3（荒诞往往不伤人，但消解攻击）。
9. **典型案例**：`你爸妈不要你喽`→`你爸妈接你来喽`；`喜欢高的？`→`你昂首挺胸走进床底大哭一场好了`；`你一来就出问题`→`那我明天去你家，顺便看看叔叔阿姨`；`你急了`→`看着马桶我尿急`；`怕他孤单`→`你可以一起去`（ke）。
10. **跨场景迁移**：
    - 职场：`你这也叫加班？`→`对，我加班是按秒计费的，你那种算监工。`
    - 恋爱：`你怎么又胖了`→`对啊，胖点好，省得别人惦记。`
    - 陌生：`你踩我鞋了`→`没事，我正打算送你这双。`
    - 网络：`你懂个屁`→`我懂个屁，那你是屁里挑刺的？`

---

### M6 · 装傻 · 留白（装听不懂 / 给错位短话）

1. **核心逻辑**：假装没听懂对方在攻击什么，给一句**错位/看似无关**的短话，让对方无从继续。
2. **解决什么问题**：对方阴阳/话里有话、想把你绕进去时，用"听不懂"让对方的招落空。
3. **适用场景**：被含沙射影、被带节奏、不想正面应战、对方说话不好接时。
4. **不适用场景**：对方把话挑明了、你在关键场合需要正面回应时（装傻会显得回避）。
5. **核心结构**：假装只听到字面 → 给一个字面相关的错位回应 → 不接潜台词，不解释。
6. **生成步骤**：①忽略对方潜台词；②只就"字面"回一句错位话；③戛然而止。
7. **语气**：无辜装傻 / 冷淡 / 幽默。
8. **强度**：1–3（柔和的防御，但能把人噎住）。
9. **典型案例**：`你有对象吗`→`有一些 / 他们有家`（cuihun）；`喂，你不认识我了？`→`忘了备注，请问你是`（reject）；`你到底懂不懂`→`你说哪里`（taimingan）。
10. **跨场景迁移**：
    - 职场：`你最近是不是摸鱼`→`摸鱼？那是什么鱼，好吃吗。`
    - 恋爱：`你是不是不爱我了`→`爱？我们不是还在吃火锅吗。`
    - 家庭：`你咋还不找工作`→`找工作？我打算先环游世界。`
    - 陌生：`你是不是在看我`→`看哪？我近视。`

---

### M7 · 冷处理（高姿态终止 · 不给抓手）

1. **核心逻辑**：不接内容，用**极简、高姿态**的话直接结束话题，让对方一拳打在棉花上。
2. **解决什么问题**：被纠缠、被无意义指责、被反复骚扰时，最快切断对话又不失姿态。
3. **适用场景**：对方恶意纠缠、网络杠精、职场无意义的挑刺。
4. **不适用场景**：关系还想维护的人（冷处理会伤感情）；需要表达立场的重要场合。
5. **核心结构**：判定"这场没有对话价值" → 给一句极简、不给接话抓手的话 → 停止。
6. **生成步骤**：①判断要不要继续；②选一句最短的收尾；③不再追加解释。
7. **语气**：高冷 / 冷淡 / 强硬。
8. **强度**：3–5（不伤人但极有压迫感）。
9. **典型案例**：`情绪问题不用和我反馈`、`你叫什么名字来着`（reject）、`少说废话`（buhequn）。
10. **跨场景迁移**：
    - 职场：`你能力不行`→`行不行，不归你评定。`
    - 恋爱：`我想和你分手`→`好的小谢。`（一句收尾，不纠缠）
    - 陌生：`你怎么这么没教养`→`教养不是给你看的。`
    - 网络：`你作者水平真不行`→`这水平确实配不上您，别看了。`

---

### M8 · 立边界（明确拒绝越界 · 不解释）

1. **核心逻辑**：对方越界（使唤/打听/侵犯），**明确拒绝，且不加解释**。解释 = 给对方讨价还价的余地。
2. **解决什么问题**：被使唤干活、被打探隐私、被无限索取时，守住边界。
3. **适用场景**：同事使唤、无休止打听、家人越界安排、不合理的请求。
4. **不适用场景**：一次性的合理请求、对方是你想维护的关系且请求不过分时。
5. **核心结构**：识别"这是越界" → 用一句不解释的拒绝/反向指令 → 不进入"为什么不行"的讨论。
6. **生成步骤**：①判断是否越界；②给一个不解释的拒绝或把动作原样抛回；③停止。
7. **语气**：强硬 / 冷淡 / 犀利。
8. **强度**：3–5。
9. **典型案例**：`你帮我把地拖了`→`拖把不是声控的`；`你出去就干净了`（tuodi）。
10. **跨场景迁移**：
    - 职场：`顺便帮我也改一下`→`改可以，排单先排上。`
    - 家庭：`你工资借我点`→`钱的事，我跟你没法商量。`
    - 朋友：`帮我做个东西呗`→`我的时间也是时间。`
    - 陌生：`加个微信吧`→`不了，我通讯录满了。`

---

### M9 · 自嘲接梗（先自贬化解攻击）

1. **核心逻辑**：对方拿你的某个点开涮时，**自己先接梗自贬**，让对方的攻击失去着力点，还显得你松弛。
2. **解决什么问题**：被围攻外貌/身高/条件、被开恶劣玩笑时，用幽默化解而不失体面。
3. **适用场景**：关系较近的互怼、当众被开涮、想轻松收场。
4. **不适用场景**：对方是恶意攻击且你想立威时（自嘲会显得软弱）；对方当众羞辱你时。
5. **核心结构**：主动承认对方说的"点" → 用自嘲/夸大把它变成梗 → 不让对方占上风。
6. **生成步骤**：①大方认下那个点；②用荒诞/夸张自嘲；③把节奏拉回自己这边。
7. **语气**：幽默 / 调侃 / 无厘头。
8. **强度**：1–2（化解为主，基本不伤人）。
9. **典型案例**：`你喜欢高的？`→`是，所以我配你刚好`（shengao 的自嘲化解方向）；`你顶嘴`→`你更厉害啊，我顶十句你还能接一句`（dingzui，自嘲+捧杀）。
10. **跨场景迁移**：
    - 职场：`你这进度可真快`→`是，快到领导都以为我摸鱼了。`
    - 恋爱：`你又笨又懒`→`对，所以我这辈子就赖你了。`
    - 朋友：`你最近胖了`→`对啊，垫在你心口的位置。`
    - 陌生：`你个子真矮`→`是，矮到刚好抬头看您摔跤。`

---

### G1 · 目标模式：关心 · 接住情绪（安抚）

1. **核心逻辑**：对方示弱/求助（累/难过/低落）时，**先接住情绪，再用轻调侃化解沉重**——是"目标"是让 TA 好受，不是反击。
2. **解决什么问题**：恋人/好友说累、说难过、情绪低时，不空洞安慰、不沉重说教。
3. **适用场景**：crush/恋人/好友示弱、需要陪伴和接住情绪时。
4. **不适用场景**：对方在严肃危机（工作被辞、亲人出事）需要实际解决时，光接情绪不够。
5. **核心结构**：识别情绪求助 → 先用一句话接住（"我在/我知道"）→ 给一句轻调侃或暖心话，不沉重。
6. **生成步骤**：①判断对方是要解决还是要被接住；②先接情绪不评判；③用轻调侃/俏皮收尾。
7. **语气**：温柔 / 调侃 / 轻松。
8. **强度**：1–2（基本无攻击，纯安抚）。
9. **典型案例**：`我好累`→`走上坡路是会累一点啦`；`晚上那种兼职要不别干了吧`（haolei）。
10. **跨场景迁移**：
    - 职场：`这周好累`→`累就对了，说明你在往上走。`
    - 恋爱：`我好难过`→`难过了先找我，我这儿有糖。`
    - 朋友：`我考试又挂了`→`挂一次叫运气，挂两次叫给你换条路。`
    - 家庭：`工作好烦`→`烦就回来，家里有饭。`

---

### G2 · 目标模式：撩 · 暧昧推拉

1. **核心逻辑**：目标不是回怼，而是**拉近距离/试探**。用忽近忽远、留白、小钩子，让对方忍不住来接。
2. **解决什么问题**：破冰、暧昧拉扯、被已读不回、想升温时。
3. **适用场景**：crush/暧昧对象/恋人之间，破冰、试探、逗对方。
4. **不适用场景**：对方明确拒绝或严肃谈正事时；陌生人（会显得油腻）。
5. **核心结构**：给对方一句"留白/钩子" → 收放结合（给一点又撤一点）→ 引导对方主动接。
6. **生成步骤**：①判断是不是"撩"的场合；②给一句带钩子的话；③不把话说完，留空间。
7. **语气**：俏皮 / 调侃 / 无辜。
8. **强度**：1–2（进攻性低，拉扯为主）。
9. **典型案例**：`已读不回`→`你不要我了，我自己想的`；`在干嘛`→`在呼吸，在等好心帅哥给我发腹肌`（renji）；`找话`→`我们的关系降温了，你说话能烧一点吗，这样就热了`（zhaohua）。
10. **跨场景迁移**：
    - 暧昧：`你最近是不是躲我`→`躲你干嘛，我还想让你请我吃饭呢。`
    - 恋爱：`你今天怎么不理我`→`我在想，怎么让你主动来找我。`
    - 同学：`你怎么老看我`→`看你什么时候发现我在看你。`
    - 网聊：`你头像真好看`→`好看吧，专门挂出来钓你的。`

## 四、现有 8 个 strategy 的重新分类

| 现状 | 判定 | 结论 |
|---|---|---|
| 不接前提 | 真·招式（守势总纲） | **保留**（M1），并作为反问/扣回/装傻/冷处理的共同基础 |
| 反打回 | 真·招式，但太粗 | **拆分** → 反问施压(M2) + 扣回·诛心(M3)；"转移"并入这两者 |
| 阴阳 | 是语气，不是招式 | **降级为语气标签**；其动作内核独立成「捧杀(M4)」 |
| 装傻 | 真·招式 | **保留**（M6 装傻·留白） |
| 高冷 | 是语气，不是招式 | **降级为语气标签**；动作内核独立成「冷处理(M7)」 |
| 荒诞 | 真·招式 | **保留**（M5 荒诞化） |
| 转移 | 是招式子集，不独立 | **删除**，并入 反问/装傻/荒诞 |
| 安抚 | 是目标模式，不是冲突招式 | **升级为目标模式 G1·关心·接住情绪** |

**新增缺失招式**：扣回·诛心(M3)、捧杀(M4)、立边界(M8)、自嘲接梗(M9)、撩·暧昧推拉(G2)。

> 判断依据：招式="做什么动作"（可迁移、跨场景成立）；语气="用什么感觉说"；目标模式="这场要达成什么"（关心/撩）。

## 五、最终 Skill 生成架构

```
用户输入（对方原话 + 场景）
   │
   ├─ 1 解析：谁在什么场合对我说了什么
   │     · 提取对方的动作：贴标签/质疑能力/阴阳/命令/贬低/示弱/撩
   │     · 关系：平级 / 权力 / 亲密 / 长辈 / 陌生
   │     · 场合：公开 / 私下 / 多人 / 网络
   │     · 用户目标：回怼 / 化解 / 撩 / 安慰 / 立边界 / 不撕破脸
   │
   ├─ 2 判断风险 / 边界 → 定"强度上限"
   │     · 权力关系 / 人多场合 → 禁强攻，倾向捧杀/装傻/冷处理
   │     · 想维护的关系 → 限温和招式
   │     · 用户记忆里对方很烦 → 可放宽强度，但结合本轮场景，不一刀切
   │
   ├─ 3 选招式：按「冲突类型 × 目标 × 关系/场合」匹配 2-3 个候选招式
   │     · 冲突类型 → 招式路由（见下方映射）
   │
   ├─ 4 定语气 + 强度(1-5)：由关系/场合/用户记忆/目标共同决定
   │
   ├─ 5 取参考：检索知识库同招式/同冲突的现成案例，作为"风格参照"（不是照抄）
   │
   ├─ 6 按招式结构骨架现场生成 2-3 条（不同强度档：稳 / 中 / 狠）
   │
   ├─ 7 自检（不合格则换招式重生成）：
   │     · 像真人？不像 AI？没机械套模板？没脱离语境？
   │     · 没过激攻击？没莫名上价值？没"为高情商变窝囊"？
   │
   └─ 8 输出（默认直接给最优 1-2 条；需要时给 稳/中/狠 档）
```

**冲突类型 → 招式映射（路由表）**
- 被质疑能力/身份/人品 → 不接 +（反问 / 扣回 / 捧杀）
- 被贴标签（敏感/急了/爱表现）→ 不接 + 扣回
- 被阴阳 / 话里有话 → 装傻 / 捧杀 / 反问
- 被使唤 / 越界 / 被索求 → 立边界
- 被当众开涮 / 开恶劣玩笑 → 荒诞 / 自嘲 / 捧杀
- 被纠缠 / 恶意骚扰 → 冷处理
- 对方示弱求助 → 关心·接住情绪（G1）
- 暧昧破冰 / 试探 → 撩·推拉（G2）

## 七、发现的问题（诚实标注）

1. **语料不均衡**：39 个案例高度偏向"回怼"，`立边界(M8)` 只有 1 个案例（tuodi）、`关心(G1)` 只有 2-3 个（haolei/hong）——这两个招式**语料支撑弱**，是靠"其本性可迁移"补充的，后续要多喂这类案例才能更稳。**（不足以从语料独立验证的部分）**
2. **强度档(1-5) 与多档输出(稳/中/狠)**：现有案例没有系统标注强度，哪些话算 3 档、哪些算 5 档，**现有语料不足以判断**，需靠设计定义 + 后续用户反馈校准。
3. **M1(不接) 是"总纲"而非平级招式**：反问/扣回/装傻/冷处理都建立在"不接"上。若严格按"互斥招式"看，M1 和其他招式有包含关系。建议在实现里把 M1 作为**全局前置原则**，其余作为落地招式。
4. **阴阳/高冷是语气不是招式**：现有 8 个 strategy 把二者当招式，导致"匹配时不知匹配什么、复用时不跨场景"。必须在实现里把"语气"从"招式"拆成独立维度。
5. **部分案例 quality 参差**：`fenshou`（说分手）、`juejiao`（装疯卖傻绝交）等案例的回复偏"梗"、针对性弱，作为"招式样本"价值有限，更多是"某博主的语感"。——**不足以判断它们代表通用招式**，建议不把它们当招式锚点。

## 八、下一步代码改造建议（只说不写）

> 对应上文的招式体系，改的是"方法层"，不推翻现有答案库/检索/隔离。

1. **新增招式库文件结构**：`knowledge/moves/` 下每个招式一个 md（按上面的 10 字段模板），替代/合并现有 `knowledge/strategies/`。招式库是**有限、可穷举**的，与案例解耦。
2. **把现有 strategy 迁移**：按"第四节"的保留/拆分/降级/删除映射迁移进招式库；`阴阳/高冷`等作为**语气标签**进入 `StyleSpec`，不再当招式。
3. **改生成流程**：`mouthpiece.py` 的无 high 匹配分支，从"凭 StyleSpec 空生成"改为"先按冲突类型选招式 → 按招式结构骨架生成 → 自检"。这一步就是"未知场景不掉档"的关键。
4. **加"冲突类型→招式路由"**：内置一张路由表（见第五节），让"识别冲突类型"成为生成的前置步骤，而不是靠关键词硬匹配案例。
5. **招式与案例解耦**：case 只作为"该招式的风格参照"，不再唯一决定答案；生成时"取招式结构 + 取同招式案例的语感 + 套用户语气/强度"。
6. **自检层**：加一个"生成后自检"步骤（像不像真人/有没有AI味/过不过激/变没变窝囊），不合格换招式重生成。可用已有 `feedback` 机制吸收用户每次的修改/选择来校准招式选择与强度。
7. **数据层不动**：答案库、检索、索引、隔离层、39 case 全部保留，仅作为最高层"现成好答案"。新增招式库与路由，不动现有运行代码。（改动集中在 `mouthpiece.py` 生成逻辑 + `knowledge/moves/`）
8. **后续喂料方向调整**：不再以"扩场景"为主，而以"补弱招式"为主——优先补 `立边界 / 关心 / 自嘲 / 撩` 的样本，因为它们现有语料最薄。
