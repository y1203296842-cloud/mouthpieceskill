## 这是什么 / 不是什么

**是**：表达辅助、沟通辅助、个人嘴替。学真实人类表达**策略**，输出像你会说的话。

## 核心能力（四大项）

1. **读懂潜台词**：把聊天记录丢进来，先分析对方到底想干什么——试探、施压、甩锅、画饼、阴阳、套路，识别真实意图后再决定怎么回，不被人带着走。
2. **五种沟通风格**：阴阳怪气、回怼、高情商回复、拒绝、安慰。同一个场景，按你的目的给不同表达方式，选哪个发哪个。
3. **模仿你的说话习惯**：投喂你自己的聊天记录，学习你的用词、长度和语气，以后生成的内容像你本人说的，不是模板。
4. **长期记住你的偏好**：不断学习你的反馈（"太狠了/太长了/不像人话/这个可以"），自动调整回复方式，越用越像你，不用每次都从头教。

> **能力成熟度说明（2026-11 更新）**：
> - 回怼 / 阴阳怪气 / 拒绝：已完整（案例库 + 招式驱动，实测通过）。
> - 安慰：已上线（独立能力槽位 + 失恋等高频场景语料，走"接住情绪+轻调侃"路径，不撒鸡汤）。
> - 高情商回复：已上线（真人化话术替换旧模板，去 AI 味）。
> - 祝福：骨架级可用（节日/生日/婚礼基础话术已内置），后续按喂料扩充。

## 怎么下载

**方式一：Releases（推荐）**

1. 打开 <https://github.com/y1203296842-cloud/mouthpieceskill/releases>
2. 下载最新版本的 `personal-mouthpiece-skill-vX.X.X.zip`
3. 解压，得到一个 `personal-mouthpiece` 文件夹（里面就有 `SKILL.md`）

**方式二：直接下载仓库源码**

仓库页面右上角 `Code` → `Download ZIP`，解压后同样是 `personal-mouthpiece` 技能目录。

**（可选）核对完整性**：下载 Release 里的 `SHA256SUMS`，在终端执行：

```bash
# Windows PowerShell
Get-FileHash -Path "personal-mouthpiece-skill-vX.X.X.zip" -Algorithm SHA256
```

把算出的哈希值和 `SHA256SUMS` 里比对，一致说明文件完整。

## 怎么接入豆包工作版

豆包工作版通过「用户技能目录」识别 Skill。只需要一步：

1. 把解压后得到的 **`personal-mouthpiece` 文件夹**（里面有 `SKILL.md` 的那个文件夹），
   整个复制/移动到豆包工作版的**技能目录**（即用户级技能根目录 `.user_skills/` 下）。
2. 重启豆包工作版（或刷新技能列表）。
3. 在对话里直接说：`同事说我太敏感了怎么回`，能正常收到回怼话术就说明装好了。

> 不需要配置任何路径、密钥或环境变量。安装自检脚本在项目内已通过
> （运行 `python3 scripts/init.py` 可复查）。

**兼容其他平台（未逐一验证）**：项目按 Skill 规范组织，Claude Code / Trae / WorkBuddy
等支持 Skill 机制的宿主可直接复用 `SKILL.md` 与 `scripts/`；跨宿主适配见 `references/hosting.md`。

## 怎么开始使用（零基础版）

装好后，直接在对话里把场景丢给 AI 就行，例如：

```
同事说我太敏感了，怎么回？
→ 所以你要注意你的言行。
  不敏感还不知道你这么坏。

高铁上孩子吵，对方说"嫌吵你去坐一等座呀，他还是个孩子"，怎么怼？
→ 你不说话的时候，我还以为他没娘呢。
```

第一次使用时 AI 可能会自然地问一句"我该怎么称呼你"，告诉它就行（例如"叫我小明"）。

## 怎么修改个人偏好（不需要打开任何文件）

直接用自然语言说，系统会自动记住（只影响你自己，不影响别人）：

| 你想做的 | 直接说 |
|---|---|
| 记住称呼 | 以后叫我小明 |
| 更狠一点 | 以后给我狠一点，我喜欢阴阳怪气的 |
| 温柔一点 | 以后温柔一点，别太狠 |
| 短一点 / 长一点 | 以后回答短一点 |
| 不喜欢的风格 | 我不喜欢太脏的话 |
| 恢复默认风格 | 恢复默认 |

- 个人偏好保存在各自的用户目录（`memory/users/<用户ID>/`），**互不覆盖**。
- 没有设置偏好的新用户，自动使用内置的**默认能力**（历史打磨的优质回怼经验），无需训练。
- 想清掉自己的偏好回到出厂默认：说"恢复默认"。

## 怎么让 Skill 记住称呼

说：`叫我小明` / `以后叫我阿甘` 即可。称呼保存在你的用户记忆里，
之后 AI 只会在合适的时候偶尔用一下，不会每条回复都机械叫名字。
想改称呼，再告诉它一次新的即可。

## 怎么更新版本

1. 下载新版本 ZIP。
2. **先备份你自己的数据**：`memory/` 文件夹（里面是你的称呼、偏好、人物和事件记忆）。
3. 用新版本文件夹覆盖旧文件夹（或删除旧文件夹后放入新版）。
4. 把你备份的 `memory/` 放回新项目的对应位置。
5. 运行一次 `python3 scripts/init.py` 确认安装正常。

> 版本历史见 `changelog.md`。升级不影响你的个人偏好和记忆。

## 常见问题（FAQ）

**Q1：这个「嘴替」到底是什么？**
A：一个给 AI 助手加装表达能力的 Skill。它不陪聊、不当恋爱模拟器，只做一件事：读懂你要应对的人和场合，用你本人的语气替你写话——回怼、拒绝、安慰、祝福、高情商回复。

**Q2：要在豆包里装吗？怎么装？**
A：豆包工作版支持用户技能目录。把 `personal-mouthpiece` 文件夹放进技能根目录（`.user_skills/` 下），重启客户端，然后直接说"同事说我太敏感了怎么回"验证即可。手把手步骤见上文「怎么接入豆包工作版」。

**Q3：需要懂代码吗？要装 Python 库吗？**
A：不需要。全部用 Python 标准库实现，零第三方依赖，不配置密钥，不联网调 API。有 Python 3 环境即可，自检跑 `python3 scripts/init.py`。

**Q4：要付费吗？有次数限制吗？**
A：免费。Apache-2.0 开源，可自由使用、修改、再分发，保留署名即可。

**Q5：它会不会乱说脏话、把人得罪死？**
A：默认有分寸，也给你旋钮。觉得太狠说"温柔一点"，觉得不够劲说"狠一点"，不喜欢脏话就说"我不喜欢太脏的话"，随时"恢复默认"。

**Q6：真能像我本人说话吗？**
A：可以投喂。把你平时说话的记录丢给它，它学你的用词、句长、语气；再加上长期反馈调整，越用越像你，而不是套模板。

**Q7：我的聊天记录和偏好会不会被上传？**
A：不上传。偏好与记忆存在本地 `memory/users/<你的用户ID>/` 下，跟你安装的技能目录一起躺在你自己的电脑里，且按用户隔离，多人共用一个技能目录也互不覆盖。

**Q8：会不会只有回怼能用，其他功能是半成品？**
A：当前成熟度：回怼 / 阴阳怪气 / 拒绝已完整；安慰、高情商回复已上线；祝福是骨架级（节日、生日、婚礼基础话术可用，后续靠喂料扩充）。README 里写的就是真实状态，不吹。

**Q9：和网上那些"AI 话术生成器"有什么区别？**
A：三点：①先辨析潜台词再回答，不是套模板；②学你的说话习惯，不是通用腔；③本地运行、按用户隔离记忆，不是把你的聊天记录传到别人服务器。

**Q10：Claude Code / Codex / Trae 能用吗？**
A：项目按通用 Skill 规范组织，这些支持 Skill 机制的宿主可直接复用 `SKILL.md` 和 `scripts/`，跨宿主细节见 `references/hosting.md`。豆包工作版是主要验证过的宿主。

**Q11：升级会不会弄丢我的记忆？**
A：按 README 的升级步骤走就不会：先备份 `memory/`，覆盖新版本后再放回。个人偏好和称呼都保得住。

**Q12：遇到问题去哪反馈？**
A：<https://github.com/y1203296842-cloud/mouthpieceskill/issues>，附上你输入的原话和实际输出，定位最快。
