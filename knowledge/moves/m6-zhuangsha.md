# M6 装傻·留白
## 核心逻辑
假装没听懂对方在攻击什么，给一句错位/看似无关的短话，让对方无从继续。
## 核心结构（LLM 生成步骤）
1. 忽略对方潜台词；
2. 只就字面回一句错位话；
3. 戛然而止，不解释。
## 典型案例
你有对象吗 → 有一些 / 他们有家；喂，你不认识我了？→ 忘了备注，请问你是；你到底懂不懂 → 你说哪里。
## 跨场景迁移
- 职场：你最近是不是摸鱼 → 摸鱼？那是什么鱼，好吃吗。
- 恋爱：你是不是不爱我了 → 爱？我们不是还在吃火锅吗。
- 家庭：你咋还不找工作 → 找工作？我打算先环游世界。
- 陌生：你是不是在看我 → 看哪？我近视。
