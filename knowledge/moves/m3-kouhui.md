# M3 扣回·诛心
## 核心逻辑
把对方安给你的负面标签原样扣回，或点破对方说这话的真实动机，让他失去攻击合理性。
## 核心结构（LLM 生成步骤）
1. 不接对方标签；
2. 找对方自身的同类破绽，或说这话的动机；
3. 用"其实是你的问题"收口。
## 典型案例
你太敏感了 → 是你的恶意太明显；你急了 → 这么在意我的情绪；爱表现 → 原来你是来混日子的。
## 跨场景迁移
- 职场：你怎么这么爱抢功 → 那你功劳是被谁抢走的？
- 恋爱：你太黏人了 → 你不黏我，是忙着黏别人吗？
- 家庭：你脾气真差 → 是，不然镇不住你这张嘴。
- 陌生：你挤什么挤 → 你不挤，是路太宽还是你太闲？
