# M10 质疑来源（信息来源攻击 + 感知回射）

## 核心逻辑
不否认、也不承认对方说的特征。先质问对方"你是怎么得出的"（信息来源），
再用"别人都没感觉到"否定普遍性，最后把特征源头回射给对方自己的感官（鼻子/眼睛/耳朵）。
**绝不进入"我到底臭不臭/丑不丑"的论证——站在前提上接话就是变相承认。**

## 为什么它比"攻击关注点"强
"拿脚臭说事，你是没什么别的好聊了吗？"看起来在反击，其实已经默认"脚臭"成立，
只是把火力转向对方行为——用户判定这仍算变相承认。
"你偷摸趴人家身上闻了？别人都没闻到就你闻到了，是不是你鼻子有问题，闻什么都臭？"
直接瓦解"脚臭"这个命题本身：信息来源可疑 + 感知回射。

## 核心结构（LLM 生成步骤）
1. 提取对方攻击的特征（trait）；
2. 判断信息来源是否可质疑：
   - 气味类（臭/味/脚/口/汗/狐/体味）→ 质疑"你怎么闻到的"；
   - 声音类（声/嗓/音）→ 质疑"你怎么听出来的"；
   - 主观审美类（丑/土/怪）→ 质疑"你怎么看出来的"；
   - 客观可见特征（高/矮/胖/瘦/老/穷）→ 信息来源不可质疑，改用其他招式（反问资格等），不要硬套；
3. 用"别人都没 X"否定普遍性；
4. 把特征源头回射给对方感官（鼻子臭闻什么都臭 / 耳朵有问题 / 眼光不行）。

## 典型案例（用户原话语感，锁定的口径）
- 同事说我脚臭 → 你偷摸趴人家身上闻了？别人都没闻到就你闻到了。是不是你鼻子有问题，闻什么都臭？
- 他说我声音难听 → 别人听着都没事，就你听着难受？你那耳朵得修修了吧。
- 朋友说我长得丑 → 别人都没看出来，就你看出来了？你眼睛是带滤镜的吧？

## 跨场景迁移
- 口臭/狐臭/汗味 → 同气味类：质疑"你怎么闻到的" + 鼻子回射
- 唱歌难听/嗓门大 → 同声音类：耳朵回射
- 穿得土/发型怪/气质差 → 同审美类：眼光/滤镜回射
- 不适用：对方拿客观事实当面戳（你确实迟到了）→ 用"承认事实后反击"或"拒绝评价资格"，不要质疑信息来源

## 与硬规则的关系
- 满足"不认下攻击前提"：整句不出现"我X"的复述确认；
- 满足"不硬找对称"：不攻击对方同维度（你鼻子/耳朵是回射，不是对称攻击）；
- 满足"不暴露内部"：输出只含可发送话术。
